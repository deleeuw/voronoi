\section{Introduction}\label{introduction}

\subsection{Homogeneity Analysis}\label{homogeneity-analysis}

\emph{Homogeneity Analysis (HGA)}, a.k.a. \emph{Multiple Correspondence
Analysis (MCA)}, can be introduced and implemented in many different
ways\footnote{Since PCA and MCA have three-letter
acronyms I added the G of Gifi to the HA of Homogeneity Analysis.}. We
refer to Guttman (\citeproc{ref-guttman_41}{1941}), Tenenhaus and Young
(\citeproc{ref-tenenhaus_young_85}{1985}), Bekker and De Leeuw
(\citeproc{ref-bekker_deleeuw_C_88}{1988}), Gifi
(\citeproc{ref-gifi_B_90}{1990}), Greenacre and Blasius
(\citeproc{ref-greenacre_blasius_06}{2006}), Le Roux and Rouanet
(\citeproc{ref-leroux_rouanet_10}{2010}), Husson et al.
(\citeproc{ref-husson_josse_saporta_16}{2016}), and De Leeuw
(\citeproc{ref-deleeuw_C_23}{2023}) for a bouquet of discussions and
interpretations of the equations and algorithms defining the HGA
technique.

A \emph{variable} is a function that maps on a (finite or infinite)
domain of \emph{objects} into a (finite or infinite) codomain of
\emph{values}. In HGA the data are the values of \(m\) variables on the
same \emph{carrier}, a finite subset the domain consisting of \(n\)
objects. Each variable \(j\) has a finite number \(k_j\) of
\emph{categories}. The categories constitute the \emph{range} of the
variable for the \(n\) objects in the carrier. Note that all variables
have the same carrier. Each object maps into a unique category, and each
category contains a subset of objects from the carrier. We also say that
a category has a number of objects that ``belong to'' the category.

Here is a small example with \(n=10\) and \(m=3\), taken from Gifi
(\citeproc{ref-gifi_B_90}{1990}), page 65. In the github voronoi
repository these data are in data/small.R.

\begin{verbatim}
      [,1] [,2] [,3]
 [1,] "a"  "p"  "u" 
 [2,] "b"  "q"  "v" 
 [3,] "a"  "r"  "v" 
 [4,] "a"  "p"  "u" 
 [5,] "b"  "p"  "v" 
 [6,] "c"  "p"  "v" 
 [7,] "a"  "p"  "u" 
 [8,] "a"  "p"  "v" 
 [9,] "c"  "p"  "v" 
[10,] "a"  "p"  "v" 
\end{verbatim}

The key mathematical object in HGA is the \emph{indicator matrix}, a
classical way to code categorical
data\footnote{Since the indicator matrix is the core of the Gifi 
system we avoid the irreverent alternative "dummy coding".}. For a
variable \(j\) with \(k_j\) categories it is an \(n\times k_j\) binary
matrix \(G_j\) in which each row \(i\) contains a single element equal
to one, indicating into which category the object \(i\) maps for
variable \(j\). The cross product \(D_j:=G_j'G_j\) is diagonal, with the
\emph{marginal frequencies} of the categories on the diagonal. For two
different variables the crossproduct \(C_{j\ell}=G_j'G_\ell\) is the
\(k_j\times k_\ell\) \emph{cross table} or \emph{contingency table} of
the two variables. Here are the three indicator matrices of our small
example, next to each other.

\begin{verbatim}
         a b c    p q r    u v   
 [1,] || 1 0 0 || 1 0 0 || 1 0 ||
 [2,] || 0 1 0 || 0 1 0 || 0 1 ||
 [3,] || 1 0 0 || 0 0 1 || 0 1 ||
 [4,] || 1 0 0 || 1 0 0 || 1 0 ||
 [5,] || 0 1 0 || 1 0 0 || 0 1 ||
 [6,] || 0 0 1 || 1 0 0 || 0 1 ||
 [7,] || 1 0 0 || 1 0 0 || 1 0 ||
 [8,] || 1 0 0 || 1 0 0 || 0 1 ||
 [9,] || 0 0 1 || 1 0 0 || 0 1 ||
[10,] || 1 0 0 || 1 0 0 || 0 1 ||
\end{verbatim}

We now deviate from the usual Gifi and French approaches (Husson et al.
(\citeproc{ref-husson_josse_saporta_16}{2016})) and define HGA as a form
of non-metric multidimensional scaling, using the \emph{stress} loss
function (Kruskal (\citeproc{ref-kruskal_64a}{1964a}), Kruskal
(\citeproc{ref-kruskal_64b}{1964b})).
Define\footnote{The symbol $:=$ is used for definitions}
\begin{equation}
\sigma(X,Y_1,\cdots,Y_m,\Delta_1,\cdots,\Delta_m) ):=\sum_{j=1}^m\sum_{i=1}^n\sum_{\ell=1}^{k_j}(\delta_{i\ell}^j-d(x_i,y_\ell^j))^2,\label{eq-loss1}
\end{equation} with \(d(x_i,y_\ell^j)\) the \emph{Euclidean distance}
between row \(i\) of \(X\) and row \(\ell\) of \(Y_j\) and
\(\delta_{i\ell}^j\) the corresponding \emph{disparity}. Disparities are
required to satisfy the measurement restrictions implied by the data.

HGA minimizes \eqref{eq-loss1} over all \(n\times p\) configurations
\(X\) satisfying \(X'X=I\), over all \(Y_j\), and over all \(\Delta_j\)
that satisfy \(\smash{\delta_{i\ell}^j=0}\) whenever
\(\smash{g_{i\ell}^j=1}\). All other elements of the \(\Delta_j\) are
only constrained to be non-negative.

Define \begin{equation}
\sigma_\star(X,Y_1,\cdots,Y_m):=\min_{\Delta_1,\cdots,\Delta_m}\sigma(X,Y_1,\cdots,Y_m,\Delta_1,\cdots,\Delta_m).\label{eq-loss2}
\end{equation} The minimizing disparity \(\delta_{i\ell}^j\) is equal to
zero if \(g_{i\ell}^j=1\) and equal to \(d(x_i,y_\ell^j)\) otherwise.
Consequently \begin{equation}
\sigma_\star(X,Y_1,\cdots,Y_m)=\sum_{j=1}^m\sum_{i=1}^n\sum_{\ell=1}^{k_j}g_{i\ell}^jd^2(x_i,y_\ell^j).\label{eq-loss3}
\end{equation} We can make a graphical representation of
\eqref{eq-loss3}. For variable \(j\) we plot the \(n\) points \(x_i\)
and the \(k_j\) points \(y_\ell^j\) in a joint plot (or biplot). We then
connect, with straight lines, each category point with the object points
that belong to it. For each category this defines a figure in the plot
which we call a \emph{star}. The \emph{size} of a star is the sum of
squares of the length of its lines. The loss function \eqref{eq-loss3}
for variable \(j\) is the sum of squares of the length of all \(n\)
lines in this plot, or equivalently the sum of the sizes of the \(k_j\)
stars. The total loss is the sum of star-sizes over all \(m\) plots.
Thus HGA aims to place the object-points and category-points in space in
such a way that the stars are as small as possible, i.e.~objects are as
close as possible to the categories they belong to.

Next define \begin{equation}
\sigma_{\star\star}(X):=\min_{Y_1,\cdots,Y_m}\sigma_\star(X;Y_1,\cdots,Y_m).\label{eq-loss4}
\end{equation} The minimum of \eqref{eq-loss3} over the \(Y_j\) is
attained at \(\hat Y_j:=D_j^{-1}G_j'X\). Category-points are the
centroids of the object-points belonging to the category. This makes the
stars more star-like/ If we substitute these optimal
\(\smash{\hat Y_j}\) in \eqref{eq-loss3} we see that
\(\sigma_{\star\star}(X)\) is indeed equal to the sum of squares of all
lines defining the stars. Minimizing \(\sigma_{\star\star}(X)\) over
\(X'X=I\), and thus minimizing \eqref{eq-loss1} over
\((X, Y_j,\Delta_j)\), defines HGA. Computing the solution turns out to
be a straightforward eigenvalue-eigenvector problem. The details are in
the publications we referenced at the beginning of this section.

A HGA in two dimensions produces of our small example the following
three star plots. Objects are numbered and in BLUE, categories have
bigger labels and are in RED. Note that there are ten objects, but the
sets of objects \((1,4,7)\), \((8,10)\), and \((6,9)\) have the same
\emph{profile} and consequently get mapped into the same object-point.
Thus there are at most six different object-points. The analysis
minimizes the sum of squares of the length of all black lines in the
three plots, under the condition that the matrix of object scores is
column-centered and orthonormal. We can think of the results as a form
of \emph{graph drawing}, where the graph is the union of the \(m\)
bipartite graphs of all \(m\) ``belonging to'' relations (De Leeuw and
Michailidis (\citeproc{ref-deleeuw_michailidis_C_00}{2000}), Michailidis
and De Leeuw (\citeproc{ref-michailidis_deleeuw_A_01}{2001})).

\subsection{Voronoi Homogeneity
Analysis}\label{voronoi-homogeneity-analysis}

Although using loss function \eqref{eq-loss1} makes HGA a form of
non-metric multidimensional scaling there are some important differences
with the more familiar MDS versions minimizing stress. There is no local
minima problem in HGA, because it turns out to be a symmetric eigenvalue
problem. In HGA, unlike in MDS, we impose the constraint \(X'X=I\).
Also, and perhaps most importantly, in HGA we do not really expect the
minimum loss function value to be zero, or even close to zero. The loss
function measures deviations from a very unrealistic ``model''. Zero
loss would imply all object-points coincide with all category-points
they belong to. This can only be realized, except in trivial cases, if
all object and category-points map into a single point, which is
prohibited by the orthonormality constraint on the object scores. Thus
we get a perfectly determinate and stable solution, at low computational
cost, but by imposing strong constraints on the disparities and a rather
arbitrary normalization. We can get around this seemingly unfortunate
situation by admitting we are not fitting or testing a ``model'', but we
are creating ``best'' drawings of the bipartite graphs that constitute
the data.

The lack of a realistic model makes it interesting to continue use the
more general loss function \begin{equation}
\sigma(X,Y_1,\cdots,Y_m,\Delta_1,\cdots,\Delta_m) ):=\sum_{j=1}^m\sum_{i=1}^n\sum_{\ell=1}^{k_j}w_{i\ell}^j(\delta_{i\ell}^j-d(x_i,y_\ell^j))^2,\label{eq-loss2}
\end{equation} with the constraints that if \(g_{i\ell}^j=1\) then
merely \(\delta_{i\ell}^j\leq\delta_{i\nu}^j\) for all
\(\nu=1,\cdots,k_j\). This is significantly weaker than the HGA
constraints, which require the \(mn\) disparities
\(\smash{\delta_{i\ell}^j}\) to be zero. If object \(i\) belongs to
category \(\ell\) of variable \(j\) we do no longer require the
object-point to coincide with the category-point, but we merely require
that the object-point is at least as close to category-point \(\ell\) as
to any of the other \(k_j-1\) category-points of that variable.

\emph{Voronoi Homogeneity Analysis} (VHA) of categorical data minimizes
loss function \eqref{eq-loss1} over \(X\), over the \(Y_j\) and over the
\(\Delta_j\) satisfying the relaxed ordinal constraints. It is
consequently another form of non-metric (ordinal) multidimensional
scaling. To be more precise, we have \(m\) linked non-metric
multidimensional unfolding problems for the binary matrices \(G_j\),
which are ``linked'' because they share the same \(X\).

Because of the different ordinal constraints on the disparities, the
plots corresponding with this analysis are different. As in HGA there is
a plot for each variable \(j\) with both \(n\) object-points and \(k_j\)
category-points. The \(k_j\) category-points are the \emph{generators}
of \(k_j\) \emph{Voronoi regions} that partition the space. Voronoi
region \(\smash{\mathcal{V}^j_\ell}\) is the region of space where the
points are at least as close to generator \(\smash{y_\ell^j}\) as to any
of the other generators of variable \(j\). And loss \eqref{eq-loss4} is
zero (for a variable) if all object-points are in the ``correct''
Voronoi region, i.e.~in the Voronoi region of the generator
corresponding with the category they belong to.

One (inefficient, but conceptually easy) way of constructing Voronoi
regions in the plane is to draw the perpendicular bisectors of the
(hypothetical) lines connecting all pairs of category-points of a
variable. In higher dimensions \(p>2\) the bisectors are planes of
dimension \(p-1\). The convex polyhedral regions thus formed, some
bounded and some unbounded, define the Voronoi
regions\footnote{In the plane a Voronoi region is unbounded if and only if its generator is on the boundary of the convex hull of all generators.}.
The literature on properties and computation of Voronoi regions is
large, and we refer to the textbooks of Okabe et al.
(\citeproc{ref-okabe_boots_sugihara_chiu_00}{2000}) and Aurenhammer et
al. (\citeproc{ref-aurenhammer_klein_lee_13}{2013}).

Since the category-point itself is obviously in its own Voronoi region
and since Voronoi regions are convex it follows that if we make stars by
connecting category-points with object points as in HGA then we actually
require each star to be in its Voronoi region. It is no longer true that
a category-point is the centroid of points of the objects belonging to
the category. The category-point can even be outside the convex hull of
the object-points belonging to the category.

The constraint \(X'X=I\) from HGA is no longer imposed directly, but we
somehow have to deal with the fact that in VHA the minimum of loss
function \eqref{eq-loss1} is always zero. The trivial solution, in which
all points and regions collapse into a single point and all \(\Delta_j\)
are zero, is always available and not excluded by the constraints. But,
perhaps more urgently, we have to deal with the types of degenerate
solutions familiar from multidimensional unfolding (Heiser
(\citeproc{ref-heiser_81}{1981}), De Leeuw
(\citeproc{ref-deleeuw_R_83}{1983}), Busing
(\citeproc{ref-busing_10}{2010})). For example, we can collapse all
category-points of a variable into a single point and put all
object-points on a sphere with the category-point at its center. Then
all distances between category and object-points are the same and we can
choose all disparities equal to that distance value and obtain loss
zero.

We will use some constraints that tend to counteract degeneracy. Also,
we always start our iterations with the HGA analysis, which in most
cases already has small loss. Then we perform iterations until either
the distances do not change from one iteration to the next (up to some
epsilon) or the loss becomes zero (up to some epsilon) or we have
reached the maximum number of iterations allowed.

\section{Algorithm}\label{algorithm}

We use an \emph{Alternating Least Squares} or \emph{ALS} algorithm,
similar to the approach used in many other non-metric scaling methods,
to minimize loss \eqref{eq-loss5}. For context, see Borg and Groenen
(\citeproc{ref-borg_groenen_05}{2005}). We alternate minimization over
\(\Delta_1,\cdots,\Delta_m\) for given \(X\) and \(Y_1\cdots Y_m\) with
minimization over \(X\) and \(Y_1\cdots Y_m\) for given
\(\Delta_1,\cdots,\Delta_m\). Using superscript \((\mu)\) for the
iteration index we can write for an ALS iteration \begin{subequations}
\begin{align}
(\Delta_1^{(\mu)},\cdots,\Delta_m^{(\mu)})&=\mathop{\text{argmin}}_{\Delta_1,\cdots,\Delta_m}\sigma(X^{(\mu)},Y_1^{(\mu)},\cdots,Y_m^{(\mu)},\Delta_1,\cdots,\Delta_m),\label{eq-als1}\\
(X^{(\mu+1)},Y_1^{(\mu+1)},\cdots,Y_m^{(\mu+1)})&=\mathop{\text{argmin}}_{X,Y_1,\cdots,Y_m}\sigma(X,Y_1,\cdots,Y_m,\Delta_1^{(\mu)},\cdots,\Delta_m^{(\mu)}).\label{eq-als2}
\end{align}
\end{subequations} The first substep \eqref{eq-als1} of iteration
\((\mu)\) solves a monotone regression problem for a simple partial
order, in which one of \(k_j\) elements must be smaller than the other
\(k_j-1\) elements. The second substep \eqref{eq-als2} solves a metric
multidimensional scaling problem. This second subproblem cannot be
solved completely, because it would need an infinite iterative process
by itself. Thus the second substep \eqref{eq-als2} consists of a finite
number of \emph{inner iterations} within the second substep of a single
ALS \emph{outer iteration}.

\subsection{Monotone Regression}\label{monotone-regression}

The \(nm\) monotone regressions are applied for each object \(i\) and
each variable \(j\). Forgetting about all these indices for the moment
we need to minimize the sum of squares \(\|\delta-d\|^2\) over
\(\delta\), where one of the elements, say \(\delta_\nu\), must be
smaller than or equal to all others.

This can be solved by using monotone regression with the primary
approach to ties (Kruskal (\citeproc{ref-kruskal_64b}{1964b}), De Leeuw
(\citeproc{ref-deleeuw_A_77}{1977})), treating all \(\delta_\ell\) with
\(\ell\neq\nu\) as ties.

\subsection{Majorization}\label{majorization}

We study the off-diagonal smacof algorithm for MDS, without taking into
account that the loss function \eqref{eq-loss1} comes from \(n\)
observations on \(m\) categorical variables. This improves and
generalizes the smacof treatment of the metric unfolding problem in
Heiser and De Leeuw (\citeproc{ref-heiser_deleeuw_A_79}{1979}).

We rewrite stress as \begin{equation}
\sigma(X,Y):=\sum_{i=1}^n\sum_{k=1}^Kw_{ik}(\delta_{ik}-d(x_i,y_k))^2.\label{eq-ploss}
\end{equation} The distance is \begin{equation}
d(x_i,y_k)=\sqrt{(X'e_i-Y'e_k)'(X'e_i-Y'e_k)}.
\end{equation} We will construct a majorization of \eqref{eq-ploss} at
\(\tilde X\) and \(\tilde Y\). Think of \(\tilde X\) and \(\tilde Y\) as
the current best estimates in a sequence of iterations. By
Cauchy-Schwartz, \begin{equation}
d(x_i,y_k)\geq\frac{1}{d(\tilde x_i,\tilde y_k)}(X'e_i-Y'e_k)'(\tilde X'e_i-\tilde Y'e_k).
\end{equation} Define the \(n\times K\) matrix-valued function
\(B(X,Y)\) by \begin{equation}
b_{ik}(X,Y):=\begin{cases}w_{ik}\frac{\delta_{ik}}{d(x_i,y_k)}&\text{ if }d(x_i,y_k)>0,\\
0&\text{ if }d(x_i,y_k)=0.\end{cases}
\end{equation} Also define the diagonal matrices \(B_{\star}(X,Y)\) with
the row-sums of \(B(X,Y)\) and \(B^{\star}(X,Y)\) with the column-sums.

If we define, as we usually do in smacof, \begin{subequations}
\begin{equation}
\rho(X,Y):=\sum_{i=1}^n\sum_{k=1}^Kw_{ij}\delta_{ij}d_{ij}(x_i,y_k)
\end{equation}
hen $\rho(X,Y)\geq\rho(X,Y;\tilde X,\tilde Y)$, where
\begin{equation}
\rho(X,Y;\tilde X,\tilde Y):=\text{tr}\ X'B_\star(\tilde X,\tilde Y)\tilde X-\text{tr}\ X'B(\tilde X,\tilde Y)\tilde Y-\text{tr}\ Y'B'(\tilde X, \tilde Y)\tilde X+\text{tr}\ Y'B^\star(\tilde X,\tilde Y)\tilde Y.
\end{equation}
Also define
\begin{equation}
\eta^2(X,Y):=\sum_{i=1}^n\sum_{k=1}^Kw_{ik}\delta_{ij}d_{ij}^2(x_i,y_k)=\text{tr}\ X'W_\star X-2\ \text{tr}\ X'WY+\text{tr}\ Y'W^\star Y,
\end{equation}
with $W_\star$ and $W^\star$ the diagonal matrices with row-sums and column-sums of
$W$, as well as the constant
\begin{equation}
C:=\sum_{i=1}^n\sum_{k=1}^Kw_{ik}\delta_{ik}^2
\end{equation}
\end{subequations}

With these definitions \begin{equation}
\sigma(X,Y)=C-2\ \rho(X,Y)+\eta^2(X,Y),
\end{equation} and \(\sigma(X,Y)\leq\sigma(X,Y;\tilde X, \tilde Y)\),
where \begin{equation}
\sigma(X,Y;\tilde X, \tilde Y):= C-2\ \rho(X,Y;\tilde X,\tilde Y)+\eta^2(X,Y),
\end{equation} with equality if \(X=\tilde X\) and \(Y=\tilde Y\). In a
majorization (or MM) iteration we minimize
\(\sigma(X,Y;\tilde X, \tilde Y)\) over \(X\) and \(Y\). If the minimum
is attained at \(\tilde X\) and \(\tilde Y\) we stop the algorithm,
because we have found a stationary point. If not we have found updates
\(X^+\) and \(Y^+\) such that \begin{equation}
\sigma(X^+,Y^+)\leq\sigma(X^+,Y^+;\tilde X, \tilde Y)<
\sigma(\tilde X,\tilde Y;\tilde X, \tilde Y)=\sigma(\tilde X,\tilde Y).
\end{equation}

The stationary equations for minimizing
\(\sigma(X,Y;\tilde X, \tilde Y)\) are \begin{subequations}
\begin{align}
X&=W_\star^{-1}(WY+B_\star(\tilde X,\tilde Y)\tilde X-B(\tilde X,\tilde Y)\tilde Y),\label{eq-xy1}\\
Y&=\{W^\star\}^{-1}(W'X+B^\star(\tilde X,\tilde Y)\tilde Y-B'(\tilde X, \tilde Y)\tilde X).\label{eq-xy2}
\end{align}
\end{subequations} Alternatively \begin{equation}
\begin{bmatrix}
W_\star&-W\\
-W'&W^\star
\end{bmatrix}
\begin{bmatrix}
X\\Y
\end{bmatrix}=
\begin{bmatrix}
B_\star(\tilde X,\tilde Y)&-B(\tilde X,\tilde Y)\\
-B'(\tilde X, \tilde Y)&B^\star(\tilde X,\tilde Y)
\end{bmatrix}
\begin{bmatrix}
\tilde X\\\tilde Y
\end{bmatrix}\label{eq-xy3}
\end{equation}

The next step in each iteration could be to directly solve the system
\eqref{eq-xy3} for \(X\) and \(Y\). This approach has the disadvantage
that the order is \(n+m\), which can be quite large in applications. We
also have to take into account that the coefficient matrix of
\eqref{eq-xy3} is singular. Alternatively we can substitute the
expression for \(X\) from \eqref{eq-xy1} in \eqref{eq-xy2} and then
solve the resulting equation for \(Y\). Or we can solve the system in
\eqref{eq-xy1} and \eqref{eq-xy2} iteratively by ALS. Choose a \(Y\),
then compute \(X\) from \eqref{eq-xy1}, then use that \(X\) in
\eqref{eq-xy2} to find a new \(Y\), and so on.

In this paper we use an approach similar to ALS, which could be called
MALS for Majorization by Alternating Least Squares. In the first step of
a MALS cycle we majorize \(\sigma(X,\tilde Y)\) and minimize
\(\sigma(X,\tilde Y;\tilde X,\tilde Y)\). Thus we treat the loss as a
function of \(X\) only, and by the earlier results in this section we
have \begin{subequations}
\begin{equation}
X^+=W_\star^{-1}(W\tilde Y+B_\star(\tilde X,\tilde Y)\tilde X-B(\tilde X,\tilde Y)\tilde Y).\label{eq-xy4}
\end{equation}
The next step, in the same MALS iteration, is to us this new $X^+$ and minimize
$\sigma(X^+,Y;X^+,\tilde Y)$ over $Y$, giving
\begin{equation}
Y^+=\{W^\star\}^{-1}(W'X^+)+B^\star(X^+,\tilde Y)\tilde Y-B'(X^+, \tilde Y)X^+)
\end{equation}
\end{subequations} Then proceed to the next two-step MALS iteration,
using the new \(X^+\) and \(Y^+\).

One advantage of MALS, shared with ALS, is that the only matrix
inversion needed is of thee diagonal weight marginals. Also there is no
need to work with square symmetric matrices of order \(n+m\). But the
main advantage of MALS is that it can easioly incorporate various
constraints on \(X\) and \(Y\). Remember that \begin{equation}
\sigma(X, \tilde Y;\tilde X,\tilde Y)=\text{tr}\ X'W_\star X-2\ \text{tr}\ X'\{W\tilde Y-\text{tr}\ X'B_\star(\tilde X,\tilde Y)\tilde X+\text{tr}\ X'B(\tilde X,\tilde Y)\tilde Y\}+C,
\end{equation} where \(C\) is now used generically for terms not
involving \(X\). Define \begin{equation}
\overline X:=W\tilde Y-\text{tr}\ X'B_\star(\tilde X,\tilde Y)\tilde X+\text{tr}\ X'B(\tilde X,\tilde Y)\tilde Y
\end{equation} Then, after completing the square, \begin{subequations}
\begin{equation}
\sigma(X, \tilde Y;\tilde X,\tilde Y)=\text{tr}\ (X-\overline X)'W_\star(X-\overline X)+C.
\end{equation}
Thus minimizing $\sigma(X, \tilde Y;\tilde X,\tilde Y)$ over $X$ that must
satisfy some constraints means projecting $\overline X$ in the diagonal
$W_\star$ metric on the set defined by the constraints. Of course in the
same way
\begin{equation}
\sigma(\tilde X, Y;\tilde X,\tilde Y)=\text{tr}\ (Y-\overline Y)'W^\star(Y-\overline Y)+C.
\end{equation}
\end{subequations}

\subsection{Regression Constraints}\label{regression-constraints}

In this paper we (optionally) use the constraints \begin{equation}
\sum_{\ell=1}^{k_j}w_{i\ell}^j(\delta_{i\ell}^j-\overline{\delta}_{ij})^2=w_{i\star}^j,\label{eq-norm}
\end{equation} for all \(i\) and \(j\), with
\(\smash{\overline{\delta}_{ij}}\) the weighted mean of the
\(\smash{\delta_{i\ell}^j}\). In addition, of course, the
\(\delta_{i\ell}^j\) must satisfy the ordinal constraints. Constraint
\eqref{eq-norm} explicitly excludes the possibility that the
\(\smash{\delta_{i\ell}^j}\) for given \(i\) and \(j\) are equal for all
\(\ell\).

Suppose \(y\) is a vector with \(n\) elements. The problem we study is
to minimize \(\sigma(x):=\|x-y\|_W^2\) over \(x\in K\) and
\(\|x-\overline x e\|_W^2\) is equal to some constant \(c\). Here

\begin{itemize}
\tightlist
\item
  \(K\) is the cone of vectors defined by a number of inequalities of
  the form \(x_i\leq x_j\),
\item
  \(e\) is the vector with all \(n\) elements equal to one,
\item
  \(W\) is a diagonal matrix of weights,
\item
  \(\|x\|^2_W=x'Wx\) is the square of the \(W\)-norm of \(x\),
\item
  \(\overline x\) is the weighted mean \(e'Wx/e'We\).
\end{itemize}

Define \(J:=I-ee'W/(e'We)\) and \(\tilde x=Jx\). Then
\(Jx=x-\overline x e\). Then \(x'Jx=\tilde x'W\tilde x\) and \(x\in K\)
if and only if \(\tilde x\in K\). Also \(\tilde x= Jx\) if and only if
\(x=\tilde x+\beta e\). So the transformed problem is to minimize
\(\|\tilde x+\beta e-y\|_W\) over \(\beta\) and \(\tilde x\in K\), with
\(e'W\tilde x=0\) and \(\tilde x'W\tilde x=c\). The minimizer for
\(\beta\) is \(\overline{y}:=e'Wy/e'We\), and thus the equivalent
``reduced'' problem becomes minimizing \(\|\tilde x- Jy\|_W^2\) over
\(\tilde x\in K\), \(\tilde x'W\tilde x=c\), and \(e'W\tilde x=0\).

Forget about the constraint \(e'W\tilde x=0\) for now. If \(M\) is the
monotone regression operator it follows that the solution for
\(\tilde x\) is \(\sqrt{c}M(Jy)/\|M(Jy)\|_W\), which automatically
satisfies \(e'W\tilde x=0\) (Bauschke et al.
(\citeproc{ref-bauschke_bui_wang_18}{2018})). Thus the solution of our
original problem is \[
\hat x=\sqrt{c}\frac{M(y-\overline{y})}{\|M(y-\overline{y})\|_W}+\overline{y}e.
\] This can be rewritten in a perhaps more revealing way. Now
\(M(y-\overline{y}e)=M(y)-\overline{y}e\) and
\(e'WM(y)=e'Wy=e'We\overline{y}\). Thus
\(\|M(y-\overline y)\|_W^2=\|M(y)\|_W^2-e'We\overline{M(y)}^2\) so that
\[
\hat x=\frac{M(y)-\overline{y}e}{\|M(y-\overline{y})\|_W}+\overline{y}e=
\frac{1}{\|M(y-\overline{y})\|_W}M(y)+\left\{1-\frac{1}{\|M(y-\overline{y})\|_W}\right\}\overline{y}e
\]

\subsubsection{Column-Centering}\label{column-centering}

If we require \(X'W_re=0\) then the stationary equations are
\(W_r(X-\overline X)=W_re\lambda'\) and thus \(X=\overline X+e\lambda'\)
with \(\lambda'=-e'W_r\overline X/e'W_re\) or \[
X=(I-\frac{ee'W_r}{e'W_re})\overline X
\]

This is different from updating \(X\) as \(J_n\tilde X\) and \(Y\) as
\(\tilde Y-n^{-1}ee'\tilde X\). With this alternative update, in which
we subtract the column-means of \(\tilde X\) from both \(\tilde X\) and
\(\tilde Y\), the distances are the same before and after centering.
Thus the distances in all iterations, and consequently the loss function
values, are the same with or without this type of centering.

\subsubsection{Orthogonality}\label{orthogonality}

If we require \(X'W_\star X=I\) we have the stationary equations
\(\overline X=XM\), with \(M\) a symmetric matrix of Lagrange
multipliers. Thus \[
X=\text{procrustus}(\overline X):=\overline X(\overline X'W_\star \overline X)^{-\frac12}.
\] If we require both \(X'W_\star X=I\) and \(X'W_\star e=0\) we have \[
X=\text{procrustus}((I-\frac{ee'W_\star }{e'W_\star e})\overline X)
\]

\subsubsection{Rank Constraints}\label{rank-constraints}

One of the main themes in Gifi (\citeproc{ref-gifi_B_90}{1990}) is that
the \(k_j\times p\) matrices of category-scores can be constrained to be
of rank \(r<p\). We will restrict ourselves in this paper to \(r=1\),
which defines what Gifi calls \emph{single quantifications}. If all
variables are restricted to have single quantifications then a HGA
becomes equivalent to a PCA of the transformed variables.

In VHA the Voronoi regions of single variables become parallel strips.
The category-points of a variable are on a line through the origin, and
the Voronoi lines or planes are parallel and perpendicular to the line
with the category-points.

\[\text{tr}\ (Y-za')'W_c(Y-za')=-2z'W_cYa+z'W_cz.a'a\]

So rank one approximation of \(\tilde Y+n^{-1}ee'(X-\tilde X)\). If
\(X\) is column-centered then of course \(\tilde Y-ee'\tilde X)\).

\subsubsection{Centroid}\label{centroid}

A more complicated restriction is \(Y=D^{-1}G'X\), possibly together
with \(X'X=I\) and \(e'X=0\). The \emph{centroid constraints}
effectively eliminate the \(Y_j\) from the optimization problem. We have
to adapt the majorization method to take the constraints into account.

Consider a single variable \(j\) and the corresponding \(n\times k_j\)
distance matrix \(D_j(X)\). We have \(d_{i\ell}(X)=\|t\|\), where
\(t:=X'r\) and \(r:=e_i-d_l^{-1}g_l\). Now \begin{subequations}
\begin{align}
d_{i\ell}&=\sqrt{t't}\geq\frac{1}{\sqrt{\tilde t'\tilde t}}\tilde t't=\frac{1}{\sqrt{\tilde t'\tilde t}}\tilde t'X'r=\text{tr}\ X'\frac{r\tilde t'}{\sqrt{\tilde t'\tilde t}},\\
d_{il}^2&=t't=\text{tr}\ X'rr'X,
\end{align}
\end{subequations} with \(\tilde t:=\tilde X'r\).

The loss component for the variable is \[
\sigma_j(X)\leq
C-2\ \text{tr}\ X'\left\{\sum_{i=1}^n\sum_{\ell=1}^{k_j}w_{i\ell}\frac{\delta_{i\ell}}{d_{i\ell}}r_{i\ell}r_{i\ell}'\right\}\tilde X
+\text{tr}\ X'\left\{\sum_{i=1}^n\sum_{\ell=1}^{k_j}w_{i\ell}r_{i\ell}r_{i\ell}'\right\}X
\] \[
\sum_{i=1}^n\sum_{\ell=1}^{k_j}w_{i\ell}r_{i\ell}r_{i\ell}'=\sum_{i=1}^n\sum_{\ell=1}^{k_j}w_{i\ell}(e_i-d_\ell^{-1}g_\ell)(e_i-d_\ell^{-1}g_\ell)'=\\
\sum_{i=1}^nw_{i\star}e_ie_i'-2\sum_{i=1}^n\sum_{\ell=1}^{k_j}w_{i\ell}e_id_\ell^{-1}g_\ell'+\sum_{\ell=1}^{k_j}w_{\star\ell}d_\ell^{-2}g_\ell g_\ell'
\]

function is 0.3158339145. The loss function value is computed by using
\begin{equation}
\sigma_\star(X,Y_1,\cdots,Y_m):=\min_{\Delta_1,\cdots,\Delta_m}\sigma(X,Y_1,\cdots,Y_m,\Delta_1,\cdots,\Delta_m),\label{eq-losshga}
\end{equation} where \(X\) and the \(Y_j\) are the HGA solution, and
where the minimum over the \(\Delta_j\) is computed by requiring that
\(\smash{\delta_{i\nu}^j\leq\delta_{i\ell}^j}\) if
\(\smash{g_{i\nu}^j=1}\). This is \emph{not} the HGA loss function
\eqref{eq-loss2}, in which the minimum over the \(\Delta_j\) is computed
by requiring that \(\delta_{i\ell}^j=0\) whenever \(g_{i\ell}^j=1\).
Thus we evaluate the HGA solution using the VGA loss function.

For any HGA or VGA solution we can compute a Shepard diagram by plotting
the distances and disparities, pooled over all objects (individuals) and
variables. The weak regression requirements imply that many disparities
will be equal to the corresponding distances. This is illustrated by the
diagonal of Figure~\ref{fig-galo_d_dhat_hga}.

Figure~\ref{fig-galo_IQ} shows some characteristic properties of Voronoi
plots. If the objects in two categories are not well separated the
object-points will be on the perpendicular bisector of the category
pair. This is partial degeneracy due to requiring weak monotonicity. The
algorithm cannot impose strict monotonicity by placing an object in the
interior of its Voronoi region, and compromises by putting it on the
boundary. Thus the VHA plot will show object-points on lines. Some
category scores are very close, which makes the Voronoi diagram
unstable. The solution for the category-scores for IQ is

\subsection{Cetacea}\label{cetacea}

The data in Vescia (\citeproc{ref-vescia_85}{1985}) describe 36 whales,
porpoises and dolphins using 15 categorical variables. In the github
voronoi repository the data are in data/cetacea.R. Appendix C gives the
common names of the 36 species and the names of the variables.

The variables are mostly physical characteristics, but they also include
habitat and feeding. The average number of categories per variable is
about four, and almost all variables are ``nominal'' (i.e.~not
``ordinal'' and not ``numerical''). In the same book Van der Burg
(\citeproc{ref-vanderburg_85}{1985}) presents a secondary analysis of
the data with HGA and Guttman (\citeproc{ref-guttman_85}{1985}) applies
his MSA-I technique (which uses HGA as an initial configuration for its
iterations).
